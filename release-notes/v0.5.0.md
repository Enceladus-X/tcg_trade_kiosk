## v0.5.0

이번 버전은 `v0.4.0` 이후 누적된 기능 개선과 운영 안정화를 한 번에 묶은 메이저 업데이트입니다.
키오스크 화면, 관리자 대시보드, 출력 문서, CSV 작업 흐름, 가격 조정 이력 관리까지 전반적으로 손봤습니다.

### 주요 변경

#### 주문 / 출력

- 주문 견적서 출력 기능을 추가했습니다.
- 주문 영수증 출력 기능을 추가했습니다.
- 출력 문서에 `마일리지 배율`을 함께 표시합니다.
- 출력 문서에 `마일리지 적용 지급액`을 함께 표시합니다.
- 출력 문서에 카드별 `조정 사유`를 함께 표시합니다.
- 주문 카드에서 고객 정보 복사 버튼을 바로 사용할 수 있습니다.

#### 가격 조정 / 이력

- 주문 아이템별 가격 직접 수정 UI를 개선했습니다.
- 감가 퍼센트 입력으로 가격을 빠르게 조정할 수 있습니다.
- 가격 조정 사유 메모를 함께 저장할 수 있습니다.
- 주문별 가격 조정 이력을 관리자 화면에서 다시 확인할 수 있습니다.
- 가격 조정 이력을 DB에 저장하기 위한 `order_item_adjustments` 테이블 구조를 추가했습니다.
- 관련 SQL 스크립트 `_scripts/order_item_adjustments.sql`을 추가했습니다.

#### 관리자 대시보드

- 주문 검색 기능을 추가했습니다.
- 고객명, 연락처, 계좌번호, 은행명, 카드명, 카드코드, 메모 기준으로 주문을 찾을 수 있습니다.
- 카드 관리 탭의 `일괄 편집` 흐름을 강화했습니다.
- 일괄 편집에서 CSV 내보내기 기능을 추가했습니다.
- 일괄 편집에서 CSV 가져오기 기능을 추가했습니다.
- CSV 가져오기 성공/실패 메시지를 추가했습니다.
- 중복 노출되던 하단 CSV 내보내기 버튼을 제거했습니다.
- 카드 추가 탭의 확장팩 선택 UI를 커스텀 드롭다운으로 개선했습니다.
- 카드 추가 시 카드 이미지 업로드 흐름을 보강했습니다.
- 게임 로고 이미지 업로드 및 게임-탭 연결 관리 흐름을 정리했습니다.
- 통계 범위를 `오늘 / 전체`로 전환할 수 있도록 개선했습니다.
- 관리자 비밀번호 변경 기능을 유지/정리했습니다.
- 마일리지 배율 설정 UX를 개선했습니다.
- 글로벌 레어도 추가/삭제 관리 흐름을 유지/정리했습니다.

#### 키오스크 화면

- 메인 화면 탭 선택이 고정되던 문제를 수정했습니다.
- 탭 드롭다운에 `전체` 옵션을 추가했습니다.
- 게임 로고 버튼 스타일을 개선했습니다.
- 레어도 필터 동작을 정리했습니다.
- 검색 버튼과 검색 입력 흐름을 복구 및 정리했습니다.
- 카드 정렬/필터 변경 시 그리드 재등장 애니메이션을 적용했습니다.
- 장바구니 버튼과 설정 버튼의 플로팅 배치를 다듬었습니다.
- 동기화 상태 칩을 추가했습니다.
- `오프라인 / 동기화 중 / 동기화 정상` 상태를 메인 화면에서 확인할 수 있습니다.
- 마지막 업데이트 시각을 함께 표시합니다.

#### 상세 모달 / 장바구니

- 카드 상세 모달에서 `매입 추가` 시 장바구니로 날아가는 애니메이션을 추가했습니다.
- 테스트와 접근성을 위한 식별자(`data-testid`, `aria-label`)를 보강했습니다.

#### 안정화 / 버그 수정

- 중첩 버튼으로 인한 hydration 오류를 수정했습니다.
- 관리자 모달 주변 런타임 오류를 정리했습니다.
- `AnimatePresence is not defined` 오류를 수정했습니다.
- 탭 상태 동기화 과정에서 발생하던 React effect 경고를 수정했습니다.
- 구형 DB에서 `order_items.note` 컬럼이 없을 때의 fallback 처리를 보강했습니다.
- 가격을 `0원`으로 조정할 때 저장이 꼬이던 문제를 정리했습니다.
- 메모 삭제가 제대로 반영되지 않던 문제를 수정했습니다.

### 운영 참고

- 운영 DB에서 `orders`, `order_items`, `games`, `tabs`, `store_settings`, `order_item_adjustments` 컬럼 구성이 현재 버전과 호환되는 것을 확인했습니다.
- 가격 조정 이력은 `order_item_adjustments` 테이블을 통해 DB에 저장됩니다.
- 이번 릴리스 결과물은 `dist/MarinfordKiosk_v0.5.0.exe`입니다.
