## v0.5.1

원피스 카드게임 레어도 대응과 관리자 편집 흐름 정리를 중심으로 다듬은 안정화 업데이트입니다. 설정에 추가한 커스텀 레어도가 카드 추가 및 카드 수정 화면에 자연스럽게 반영되도록 정리했습니다.

### 주요 변경

#### 레어도 처리

- 원피스 카드게임 전용 레어도 색상 팔레트를 추가했습니다.
- 아래 레어도는 더 이상 해시 기반 임의 색상이 아니라 고정 색상으로 표시됩니다.
  - `L` / `리더`
  - `SR` / `슈퍼레어`
  - `SEC` / `시크릿`
  - `SP` / `스페셜`
  - `PA` / `패러렐` / `Parallel`
  - `PR` / `프로모`
- 위에 해당하지 않는 기타 커스텀 레어도는 기존처럼 해시 기반 색상 fallback을 유지합니다.

#### 관리자 화면

- 카드 추가 탭의 `레어도별 매입가`가 설정의 글로벌 레어도 목록을 그대로 반영하도록 수정했습니다.
- 카드 정보 수정 모달의 `레어도별 매입가`도 설정의 글로벌 레어도 목록을 그대로 반영하도록 수정했습니다.
- 설정에서 레어도를 추가하거나 제거했을 때, 카드 추가 / 카드 수정 폼 상태가 함께 동기화되도록 정리했습니다.

#### 안정화

- 카드 추가와 카드 수정에서 레어도 하드코딩으로 인해 새 레어도가 누락되던 문제를 수정했습니다.
- 커스텀 레어도 환경에서도 기존 저장 흐름과 fallback 동작이 유지되도록 정리했습니다.

### 운영 참고

- 이번 버전의 주요 목적은 커스텀 레어도 확장, 특히 원피스 카드게임 레어도 대응 강화입니다.
- 릴리스 결과물은 `dist/MarinfordKiosk_v0.5.1.exe` 기준으로 준비됩니다.
