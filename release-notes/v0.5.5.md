## v0.5.5

이번 업데이트는 키오스크 상단 헤더의 타이틀과 상태 정보 배치를 다시 다듬는 UI 정리 업데이트입니다. 게임 선택 버튼과 타이틀이 서로 겹치지 않도록 구조를 조정하면서도, 화면 상단 공간이 과하게 비지 않도록 배치를 다시 압축했습니다.

### 주요 변경

#### 상단 헤더 레이아웃 조정

- 상단 타이틀 배치를 다시 정리해 게임 선택 버튼과 겹치지 않도록 조정했습니다.
- 가운데 U자형 노치 구조를 고집하지 않고, 실제 사용 흐름에 맞게 더 단순한 헤더 배치로 정리했습니다.
- 타이틀이 화면 상단에서 지나치게 공간을 차지하지 않도록 상단 여백과 정렬을 다시 맞췄습니다.

#### 상태칩 / 버전칩 정리

- 동기화 상태칩과 현재 버전 칩을 화면 맨 왼쪽 위에 고정해 더 쉽게 확인할 수 있도록 조정했습니다.
- 상태칩, 버전칩, 타이틀, 탭 줄의 시각적 흐름이 자연스럽게 이어지도록 간격을 재정리했습니다.

### 버그 수정

- 상단 타이틀 영역 때문에 게임 선택 버튼이 일부 가려지거나 겹쳐 보이던 문제를 완화했습니다.
- 헤더 구조 수정 과정에서 일부 한글 라벨이 깨져 보이던 문제를 수정했습니다.

### 운영 참고

- 이번 버전은 상단 헤더의 배치 안정화가 중심이므로, 매장 디스플레이 해상도에서 실제 시인성을 한 번 더 확인하는 것을 권장합니다.
