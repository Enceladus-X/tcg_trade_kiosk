## v0.3.2

게임 카테고리, 마일리지 지급, 관리자 설정 기능을 본격적으로 도입한 확장 업데이트입니다. 고객 화면과 관리자 화면 모두 실사용 기준으로 한 단계 넓혔습니다.

### 주요 변경

- 키오스크 첫 화면에 유희왕, 원피스 등 게임 대분류 선택 구조를 도입했습니다.
- 팝업 창이 항상 화면 정중앙에 열리도록 수정했습니다.
- 화면 전환 애니메이션을 추가해 사용 흐름을 더 자연스럽게 정리했습니다.
- 현재 탭에 해당하는 카드가 없으면 관련 레어도 필터 버튼이 자동으로 숨겨지도록 개선했습니다.
- 매입 요청 시 `현금 지급`과 `마일리지 지급` 중 선택할 수 있도록 결제 방식을 확장했습니다.
- 마일리지 선택 시 설정한 보너스 비율이 자동 적용되도록 했습니다.
- 마일리지 주문에서는 불필요한 계좌 입력칸이 자동으로 숨겨지도록 정리했습니다.
- 관리자 화면에 설정 탭을 추가했습니다.
- 관리자 비밀번호 변경, 마일리지 보너스 비율 조정, 레어도 추가/삭제 기능을 지원합니다.
- 매입 목록에 카드 이미지 썸네일을 표시하도록 개선했습니다.
- 고객 연락처 수집 방식을 뒷 4자리에서 전체 전화번호 기준으로 확장했습니다.
- 고객 정보 복사 버튼으로 이름, 연락처, 계좌번호를 한 번에 복사할 수 있도록 했습니다.

### 운영 참고

- 이 버전은 `v0.2.0` 이후 기능 범위가 크게 확장된 버전으로, 업데이트 시 프로그램을 다시 다운로드해 교체 실행하는 것을 권장합니다.
