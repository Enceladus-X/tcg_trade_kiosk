## v0.5.8

매입 요청 목록에서 주문의 성격을 더 빠르게 파악하고, 가격 조정 작업을 더 안전하게 되돌릴 수 있도록 관리자 화면을 개선한 업데이트입니다. 카드 게임별 로고 표시, 가격 조정 취소, 조정 품목 식별성을 중심으로 운영 편의성을 보강했습니다.

### 핵심 개선

- 매입 요청 목록의 기본 프로필 아이콘을 제거하고, 주문에 포함된 카드의 게임 로고를 표시하도록 변경했습니다.
- 한 주문에 여러 게임의 카드가 섞여 있을 경우 최대 2개 게임 로고를 반반 클리핑 형태로 표시해, 어떤 게임 카드가 포함되어 있는지 빠르게 알 수 있게 했습니다.
- 투명 배경 로고가 어두운 화면에서 묻히지 않도록 밝은 로고 플레이트를 추가했습니다.
- 유희왕 로고는 이미지 하단이 잘리지 않도록 전용 위치/크기 보정을 적용했습니다.
- 원피스 로고는 2분할 표시 시 핵심 텍스트가 보이도록 전용 오프셋을 적용했습니다.
- 가격 조정된 매입 품목에는 `가격조정됨` 스티커를 표시해, 배경색만으로 구분해야 하던 문제를 개선했습니다.
- 가격 조정 이력 영역에 `가격 조정 취소` 버튼을 추가했습니다.
- 가격 조정 취소 시 기존 가격으로 복구하고, 감가 분리로 생성된 별도 품목은 원래 품목과 다시 합쳐지도록 처리했습니다.
- 수량이 2장 이상인 품목은 일부 장수만 감가 적용해 별도 품목으로 분리할 수 있도록 개선했습니다.
- 감가율, 수정 장수, 사유 입력 중 관리자 화면이 느려지지 않도록 입력 상태 처리 방식을 최적화했습니다.

### 레어도 표시

- `OFPSE` 및 기타 `OF` 계열 레어도는 프리즘 계열 색상으로 표시되도록 보강했습니다.
- `GRM` 레어도는 골드-블랙 계열의 전용 색상으로 표시되도록 추가했습니다.
- `OFUR`은 별도 특수 색상 처리에서 제외하고, 기존 커스텀 레어도 색상 규칙을 따르도록 되돌렸습니다.
- `P`, `★` 포함 레어도, `OFPSE` 계열의 프리즘 효과는 유지됩니다.

### 버그 수정

- 매입 요청에서 일부 수량만 감가 적용했을 때 총액이 전체 수량 기준으로 잘못 계산될 수 있던 문제를 수정했습니다.
- 감가 분리 품목이 별도 매입 품목처럼 수정되지 않던 문제를 개선했습니다.
- 가격 조정된 품목의 배경 강조는 보이지만 실제 조정 여부를 알기 어려웠던 문제를 `가격조정됨` 스티커로 보완했습니다.
- 주문 목록의 게임 로고가 투명 배경 이미지일 때 잘 보이지 않던 문제를 수정했습니다.
- 2개 게임 로고가 함께 표시될 때 한쪽 로고가 지나치게 작아지거나 일부만 보이던 문제를 조정했습니다.
- 유희왕 로고의 하단 텍스트가 슬롯 아래쪽에서 잘리던 문제를 보정했습니다.
- 카드 이미지 프리로드 타이머가 브라우저/런타임 환경에 따라 타입 충돌을 일으킬 수 있던 부분을 안정화했습니다.

### 운영 참고

- 별도 Supabase 스키마 변경은 필요 없습니다.
- 가격 조정 취소 기능은 기존 `order_item_adjustments` 테이블의 이력을 사용합니다.
- 기존 주문, 카드, 통계 데이터는 그대로 유지됩니다.
