## v0.5.8

`v0.5.7`과 비교해 매입 요청 목록의 식별성, 가격 조정 복구 흐름, 레어도 표시, 메인 화면 탭 동작을 개선한 업데이트입니다.

### v0.5.7 대비 변경점

- 매입 요청 목록의 기본 프로필 아이콘을 제거하고, 주문에 포함된 카드의 게임 로고를 표시하도록 변경했습니다.
- 한 주문에 여러 게임 카드가 섞여 있으면 최대 2개 게임 로고를 고정 슬롯 안에서 반반 표시하도록 추가했습니다.
- 투명 배경 로고가 어두운 화면에서 묻히지 않도록 밝은 로고 플레이트를 적용했습니다.
- 유희왕, 원피스 로고가 주문 목록의 작은 슬롯에서 잘리지 않도록 전용 위치 보정을 적용했습니다.
- 가격 조정된 매입 품목에 `가격조정됨` 스티커를 표시해 조정 여부를 더 명확히 알 수 있게 했습니다.
- 가격 조정 이력 영역에 `가격 조정 취소` 버튼을 추가했습니다.
- 가격 조정 취소 시 기존 가격으로 복구하고, 감가 분리로 생성된 별도 품목은 원래 품목과 다시 합쳐지도록 개선했습니다.
- 수량이 2장 이상인 품목에서 일부 장수만 감가 적용해 별도 품목으로 분리할 수 있도록 개선했습니다.
- 감가율, 수정 장수, 사유 입력 중 관리자 화면이 느려지지 않도록 입력 처리 방식을 최적화했습니다.
- `OFPSE` 및 기타 `OF` 계열 레어도는 프리즘 계열 색상으로 표시되도록 보강했습니다.
- `GRM` 레어도는 골드-블랙 계열의 전용 색상으로 표시되도록 추가했습니다.
- `OFUR`은 별도 특수 색상 처리에서 제외하고 기존 커스텀 레어도 색상 규칙을 따르도록 되돌렸습니다.
- 메인 화면의 하위 탭 분류에서 `전체` 선택이 첫 번째 탭으로 되돌아가던 문제를 수정했습니다.
- 카드 이미지 프리로드 타이머가 일부 런타임에서 타입 충돌을 일으킬 수 있던 부분을 안정화했습니다.

### 운영 참고

- 별도 Supabase 스키마 변경은 필요 없습니다.
- 가격 조정 취소 기능은 기존 `order_item_adjustments` 테이블의 이력을 사용합니다.
- 배포 파일은 `MarinfordKiosk_v0.5.8.exe`입니다.
