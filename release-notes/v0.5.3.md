## v0.5.3

이번 업데이트는 키오스크 운영 화면의 안정성과 체감 사용성을 함께 끌어올리는 데 집중했습니다. 장바구니와 관리자 매입 요청에서 항목별로 `현금 / 마일리지`를 나눠 처리할 수 있게 확장했고, 혼합 결제 저장 흐름과 관리자 편집 오류를 정리했습니다. 메인 화면에는 현재 프로그램 버전과 최신 버전 알림을 추가하고, 카드 이미지 로딩도 더 가볍게 다듬었습니다.

### 주요 변경

#### 결제 방식 확장

- 장바구니 항목마다 `현금 / 마일리지`를 개별 선택할 수 있도록 개선했습니다.
- 관리자 `매입 요청` 인라인 편집에서도 항목별 `현금 / 마일리지` 전환이 가능하도록 확장했습니다.
- 현금과 마일리지가 섞인 주문도 정상적으로 생성, 저장, 재계산되도록 주문 저장 로직을 정리했습니다.
- 항목 삭제 후에도 남은 품목 기준으로 주문 총액과 결제 상태가 다시 계산되도록 수정했습니다.

#### 장바구니 및 매입 요청 UX

- 장바구니 창 높이를 늘려 더 많은 항목을 한 번에 볼 수 있도록 조정했습니다.
- `현금 / 마일리지` 토글 시 항목이 목록 아래로 이동하던 문제를 수정해, 기존 자리에서 바로 전환되도록 바꿨습니다.
- 장바구니 확정 시 실패 응답을 기다리지 않고 성공 화면으로 넘어가던 문제를 수정했습니다.
- 오류 발생 시 `[object Object]` 대신 사용자에게 읽을 수 있는 메시지가 보이도록 정리했습니다.
- 관리자 `매입 요청` 화면에서 품목 삭제, 수량 조절, 가격 조절, 메모 입력 흐름을 계속 안정화했습니다.

#### 관리자 화면 안정화

- 혼합 결제 주문을 저장할 때 발생하던 관리자 저장 오류를 수정했습니다.
- 관리자 화면에서 결제수단 변경 후 적용 시 총액과 주문 상태가 어긋나지 않도록 보완했습니다.
- 주문 품목별 결제수단 상태를 로컬 fallback과 DB 컬럼 기준으로 함께 처리하도록 정리했습니다.
- `order_items.payment_method` 컬럼이 없는 환경을 대비한 fallback 경로를 유지하면서, 실제 운영 DB 적용용 SQL도 추가했습니다.

#### 메인 화면 및 버전 알림

- 메인 키오스크 화면 좌측 상단에 현재 프로그램 버전을 작게 표시하도록 추가했습니다.
- GitHub Releases 기준으로 더 최신 버전이 있을 경우 `새 버전` 알림이 뜨도록 구현했습니다.
- 버전 칩과 새 버전 알림을 클릭하면 릴리스 페이지로 이동하도록 추가했습니다.
- Electron 실행 환경에서는 릴리스 링크가 시스템 기본 브라우저에서 열리도록 처리했습니다.

#### 이미지 로딩 최적화

- 특정 카드 이미지가 무거울 때 첫 로딩이 답답하던 문제를 줄이기 위해, 현재 화면에 보일 카드 이미지들을 백그라운드에서 미리 프리로드하도록 추가했습니다.
- 전체 이미지를 한 번에 강제로 불러오는 방식 대신, 현재 게임/탭/검색 결과 기준 상위 카드들만 유휴 시간에 미리 받아오도록 구성해 초기 진입 부담을 줄였습니다.

#### 데이터 및 운영 스크립트

- `order_items.payment_method` 컬럼 추가용 SQL 스크립트를 포함했습니다.
- 혼합 결제 환경에서도 주문 행과 주문 항목을 함께 해석할 수 있도록 타입과 변환 로직을 정리했습니다.

### 운영 참고

- 항목별 결제수단을 운영 DB에 영속 저장하려면 `_scripts/order_items_payment_method.sql`을 Supabase에 적용하는 것이 좋습니다.
- 최신 버전 알림은 GitHub Releases API 응답을 기준으로 동작합니다. 네트워크가 없거나 GitHub 응답이 실패하면 조용히 숨겨집니다.
