## v0.5.3

이번 업데이트는 키오스크 실사용 흐름에서 체감되는 결제 UX와 안정성, 그리고 운영 편의성을 함께 다듬는 데 집중했습니다. 장바구니와 관리자 매입 요청 화면에서 항목별 `현금 / 마일리지` 처리를 지원하도록 확장했고, 혼합 결제 주문 저장 과정에서 드러난 오류와 목록 갱신 버그를 정리했습니다. 메인 화면에는 현재 프로그램 버전과 최신 버전 알림을 추가했고, 카드 이미지 로딩도 더 가볍게 개선했습니다.

### 주요 변경

#### 결제 방식 확장

- 장바구니 항목마다 `현금 / 마일리지`를 개별 선택할 수 있도록 개선했습니다.
- 관리자 `매입 요청` 인라인 편집에서도 항목별 `현금 / 마일리지` 전환이 가능하도록 확장했습니다.
- 현금과 마일리지가 섞인 주문도 정상적으로 생성되고 합계가 계산되도록 주문 저장 로직을 정리했습니다.
- 항목 삭제 이후 남은 항목 기준으로 총액과 결제 상태가 다시 계산되도록 보완했습니다.

#### 장바구니 및 매입 요청 UX 개선

- 장바구니 모달 높이를 늘려 많은 품목을 한 번에 보기 쉽게 조정했습니다.
- `현금 / 마일리지` 토글 시 항목이 목록 맨 아래로 이동하던 문제를 수정해, 같은 자리에서 바로 전환되도록 개선했습니다.
- 장바구니에서 주문 저장 완료 전에 성공 화면으로 넘어가던 흐름을 수정해, 실제 저장 성공 후에만 완료 처리되도록 변경했습니다.
- 관리자 `매입 요청` 화면에서 항목별 가격, 수량, 메모, 결제수단, 삭제 기능을 함께 안정적으로 다룰 수 있도록 보강했습니다.

#### 메인 화면 및 버전 알림

- 메인 키오스크 화면에 현재 프로그램 버전을 작게 표시하도록 추가했습니다.
- GitHub Releases 기준으로 더 최신 버전이 있을 경우 `새 버전` 알림이 표시되도록 구현했습니다.
- 버전 칩과 최신 버전 알림을 클릭하면 릴리스 페이지로 이동하도록 연결했습니다.
- Electron 실행 환경에서는 릴리스 링크가 시스템 기본 브라우저에서 열리도록 처리했습니다.

#### 이미지 로딩 최적화

- 무거운 카드 이미지 때문에 첫 화면 체감 로딩이 느리던 문제를 줄이기 위해, 현재 화면에 보이는 카드 기준 상위 이미지들을 백그라운드에서 미리 불러오도록 개선했습니다.
- 전체 이미지를 한 번에 강제 로드하지 않고, 현재 필터 기준으로 필요한 카드 위주로 프리로드해 초기 진입 부담을 줄였습니다.

#### 운영 스크립트

- `order_items.payment_method` 컬럼 추가를 위한 SQL 스크립트를 포함했습니다.
- 혼합 결제 환경에서도 주문 행과 주문 항목의 상태를 일관되게 해석할 수 있도록 관련 데이터 처리 로직을 정리했습니다.

### 버그 수정

- 장바구니에서 `현금 / 마일리지`를 전환할 때 해당 항목이 목록 맨 아래로 내려가던 버그를 수정했습니다.
- 현금과 마일리지가 섞인 주문이 관리자 대시보드에 생성되지 않거나 저장이 실패하던 문제를 수정했습니다.
- 주문 저장 실패 시 런타임 에러가 `[object Object]` 형태로만 보이던 문제를 정리해, 사용자 흐름이 더 안정적으로 유지되도록 개선했습니다.
- 관리자 `매입 요청` 화면에서 혼합 결제 주문의 조정 내용 저장 시 오류 배너가 뜨던 경로를 수정했습니다.
- 항목 삭제 후 남은 품목의 총액이나 결제 상태가 잘못 반영될 수 있던 문제를 보완했습니다.
- 릴리스 링크가 Electron 내부가 아닌 시스템 기본 브라우저에서 열리도록 수정했습니다.

### 운영 참고

- 항목별 결제수단을 운영 DB에 안정적으로 저장하려면 `_scripts/order_items_payment_method.sql`을 Supabase에 적용하는 것을 권장합니다.
- 최신 버전 알림은 GitHub Releases API 응답을 기준으로 동작하며, 네트워크 상태나 GitHub 응답 실패 시에는 조용히 숨겨집니다.
