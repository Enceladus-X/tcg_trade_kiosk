## v0.6.1

이번 업데이트는 관리자 대시보드에서 매입 요청이 많이 쌓였을 때의 체감 속도와 가격 조정 이력 확인 흐름을 개선한 안정화 버전입니다.

### 주요 변경

- 관리자 `매입 요청` 탭에서 주문 목록을 처음 30건만 표시하도록 정리했습니다.
- 더 많은 주문은 `매입 요청 N건 더 보기` 버튼으로 30건씩 추가 표시할 수 있습니다.
- 상태 필터나 검색어가 바뀌면 표시 개수가 다시 첫 30건으로 초기화되도록 했습니다.
- 현재 필터 결과에서 몇 건을 보고 있는지 `전체 N건 중 M건 표시` 형태로 안내합니다.

### 가격 조정 이력

- 가격 조정 이력 영역에 `총 N건` 배지를 추가했습니다.
- 조정 이력이 많은 주문은 기본 3건만 표시하고, 필요할 때 전체 이력을 펼쳐볼 수 있도록 했습니다.
- `전체 N건 보기`, `접기`, `숨긴 이력 N건 더 보기` 버튼을 추가해 긴 이력도 화면을 과하게 차지하지 않도록 개선했습니다.
- 기존 `가격 조정 취소` 기능은 그대로 유지했습니다.

### 운영 참고

- 별도 Supabase 스키마 변경은 필요 없습니다.
- 이번 버전은 관리자 화면 렌더링 부담을 줄이는 프론트엔드 개선입니다.
- 주문량이 더 늘어나는 장기 운영 단계에서는 Supabase 페이지네이션 또는 기간 기본 필터 도입을 추가로 검토할 수 있습니다.
- 배포 파일은 `MarinfordKiosk_v0.6.1.exe`입니다.
