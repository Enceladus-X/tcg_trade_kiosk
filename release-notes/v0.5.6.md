## v0.5.6

이번 업데이트는 관리자 정산 처리와 통계 화면의 가시성을 개선한 버전입니다. 매입 요청의 정산 방식을 더 빠르게 바꿀 수 있고, 통계 탭에서 기간별 흐름과 게임별 비중을 더 직관적으로 확인할 수 있습니다.

### 주요 변경

- 고객용 매입 목록에 `전체 현금`, `전체 마일리지` 일괄 전환 버튼을 추가했습니다.
- 관리자 매입 요청 상세에 품목별 `현금 / 마일리지` 토글을 상시 노출했습니다.
- 관리자 매입 요청 상세에 `전체 현금`, `전체 마일리지` 마스터 버튼을 추가했습니다.
- 정산 방식 변경 시 품목별 적용 금액과 주문 총액이 즉시 다시 계산되도록 정리했습니다.
- 통계 탭 범위를 `오늘 / 일주일 / 전체` 순서로 개편했습니다.
- `오늘` 탭에서는 당일 요약과 게임별 비중만 보여주도록 정리했습니다.
- `일주일` 탭에서는 최근 7일 추이를 표시합니다.
- `전체` 탭에서는 최근 30일 추이를 표시합니다.
- 게임별 매입 비중을 도넛 차트와 비율 바로 확인할 수 있도록 개선했습니다.
- 통계 화면을 PNG 이미지로 저장할 수 있는 기능을 추가했습니다.
- 통계 데이터를 CSV 표로 저장할 수 있는 기능을 추가했습니다.
- CSV 저장 시 TOP 카드만이 아니라 집계된 전체 카드 목록을 포함하도록 변경했습니다.

### 버그 수정

- 통계 탭에서 일부 한글 라벨이 깨져 보이던 문제를 수정했습니다.
- `오늘` 탭에서 최근 7일 추이가 함께 보여 맥락이 어색하던 문제를 정리했습니다.
- 정산 방식 일괄 전환 시 같은 카드/레어도 항목이 자연스럽게 병합되도록 보완했습니다.

### 운영 참고

- 통계 차트는 현재 로드된 주문, 카드, 게임, 탭 데이터를 기반으로 계산합니다.
- 주문량이 크게 늘어나면 Supabase View 또는 RPC 기반 서버 집계로 이전하는 것을 권장합니다.
- 이미지 저장 기능을 위해 `html-to-image` 의존성이 추가되었습니다.
