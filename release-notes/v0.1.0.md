## v0.1.0

TCG 매입 키오스크의 첫 공개 버전입니다. 별도 설치 없이 실행 가능한 포터블 형태로 배포했으며, 관리자 PIN 기반 진입 구조를 함께 제공합니다.

### 주요 변경

- 포터블 실행 파일 형태로 배포해 별도 설치 없이 바로 사용할 수 있도록 구성했습니다.
- 카드 데이터와 기본 리소스를 실행 파일에 포함해 현장 배포 절차를 단순화했습니다.
- 관리자 화면에 PIN 인증 진입 구조를 적용했습니다.
- `config.json`을 통해 관리자 PIN을 외부에서 변경할 수 있도록 했습니다.

### 설치 및 초기 설정

- 릴리스의 **Assets**에서 실행 파일을 다운로드합니다.
- 원하는 폴더에 복사한 뒤 실행 파일을 더블클릭해 바로 사용할 수 있습니다.
- 기본 관리자 진입 경로는 우측 상단 `설정` 버튼 → PIN 입력입니다. 관리자 PIN은 현장 운영 환경에서 별도로 설정해 사용합니다.
- 관리자 PIN을 바꾸려면 실행 파일과 같은 폴더에 `config.json`을 만들고 아래 형식으로 입력합니다.

```json
{ "adminPin": "원하는 4자리" }
```

### 운영 참고

- 초기 배포 버전이므로 현장 배포 전 카드 데이터와 관리자 PIN 설정을 함께 확인하는 것을 권장합니다.
