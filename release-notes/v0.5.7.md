## v0.5.7

통계 화면에서 기간별 데이터를 더 명확하게 확인할 수 있도록 `30일` 전용 탭을 추가하고, `전체` 통계의 추이 차트를 실제 운영 기간에 맞게 자동 집약하도록 개선한 업데이트입니다.

### 핵심 개선

- 통계 기간 선택을 `오늘 / 7일 / 30일 / 전체` 순서로 재정리했습니다.
- `30일` 탭을 추가해 최근 30일 주문만 따로 모아 요청 총액, 지급 완료, 지급 방식, 매수, 게임별 비중, 인기 매입 카드를 확인할 수 있게 했습니다.
- `전체` 탭은 전체 누적 집계를 유지하되, 추이 차트는 실제 데이터 기간에 따라 자동으로 일별, 주별, 월별 표시로 전환되도록 개선했습니다.
- 전체 데이터가 30일 이하인 경우에는 일별 추이를 표시하고, 30일 초과부터는 주별, 90일 초과부터는 월별로 묶어 장기 운영 시에도 차트가 과밀해지지 않도록 했습니다.
- 통계 CSV에는 `전체` 탭의 자동 집약 추이 데이터도 함께 포함되도록 보강했습니다.

### 버그 수정

- 통계 카드의 `집계 매수`가 7일 데이터 기준으로 고정되어 보일 수 있던 문제를 수정했습니다.
- 차트 Y축의 `100만` 같은 긴 단위 라벨이 왼쪽에서 잘리던 문제를 수정했습니다.
- `전체` 탭의 추이 차트가 `30일` 탭과 같은 의미로 보일 수 있던 구조를 개선했습니다.
- 통계 기간 버튼 라벨을 안정적인 문자열 처리로 정리해 한글 표시가 깨질 가능성을 줄였습니다.

### 운영 참고

- 별도 Supabase 스키마 변경은 필요 없습니다.
- 기존 통계 이미지 저장 및 CSV 저장 기능은 그대로 유지됩니다.
