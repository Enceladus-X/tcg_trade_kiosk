## v0.3.6

매입 목록 모달의 레이아웃 문제를 긴급 수정한 안정화 업데이트입니다.

### 주요 변경

- 카드 수가 많을 때 매입 목록 모달 내부 스크롤이 동작하지 않던 문제를 수정했습니다.
- `[판매 확정]` 버튼이 화면 밖으로 밀려 내려가던 치명적 레이아웃 문제를 수정했습니다.
- ScrollArea 기반 구조를 단순한 스크롤 컨테이너 구조로 교체해 flex 계산 문제를 정리했습니다.
- 헤더와 푸터가 레이아웃 압축 과정에서 무너지는 현상을 방지하도록 보정했습니다.

### 운영 참고

- 카드 수가 많은 주문에서도 모달 내부 스크롤과 하단 액션 버튼이 정상적으로 유지됩니다.
