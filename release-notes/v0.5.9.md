## v0.5.9

이번 업데이트는 카드별 매입 가능 상태를 더 세밀하게 관리하고, 매입 요청 처리 실수를 줄이며, 관리자 통계 확인 범위를 넓힌 운영 안정화 버전입니다.

### 주요 변경

- 카드 관리 화면에서 레어도 칩을 클릭해 특정 레어도/가격만 매입 중지 또는 재개할 수 있도록 추가했습니다.
- 카드 전체를 중지하지 않아도 `SR`, `UR`, `PSE`처럼 필요한 가격대만 선택적으로 매입 제외할 수 있습니다.
- 카드 수정 저장 시 중지된 레어도의 기존 가격은 삭제하지 않고 보존하도록 개선했습니다.
- 카드 전체 매입 중지 시에도 등록된 가격 기준으로 모든 레어도 상태가 안정적으로 비활성화되도록 보강했습니다.

### 매입 요청

- 매입 요청을 거절할 때 즉시 처리되지 않고 `거절 확인` 단계를 거치도록 변경했습니다.
- 거절 확인 단계에서 `취소`를 눌러 실수로 누른 거절 작업을 중단할 수 있습니다.
- 이미 거절된 매입 요청에는 `거절 취소` 버튼을 추가해 다시 대기 상태로 되돌릴 수 있습니다.

### 통계

- 통계 화면의 인기 매입 카드 목록 표시 범위를 `TOP 10`, `TOP 20`, `TOP 50`, `전체`로 전환할 수 있도록 추가했습니다.
- 기존에는 상위 10개 카드만 확인할 수 있었지만, 이제 매입 누적 카드 전체를 더 넓게 검토할 수 있습니다.

### 운영 참고

- 별도 Supabase 스키마 변경은 필요 없습니다.
- 배포 파일은 `MarinfordKiosk_v0.5.9.exe`입니다.
