## v0.6.2

이번 업데이트는 매장 운영 환경에 맞춘 화면 모드와 카드 검수·매입 설정의 세부 제어를 추가한 운영 기능 개선 버전입니다.

### 화면 모드

- 관리자 `설정`에서 `전체화면`과 `창모드`를 즉시 전환할 수 있습니다.
- 선택한 화면 모드는 프로그램을 종료한 뒤 다시 실행해도 유지됩니다.
- 창모드는 작업 표시줄과 다른 프로그램을 함께 사용해야 하는 운영 환경에 맞춰 적절한 크기로 열립니다.

### 카드 관리

- 카드 정보 수정 화면을 관리자 대시보드에서 바로 연 경우 `취소`를 누르면 즉시 대시보드로 복귀합니다.
- 레어도별 매입가 설정에 각 레어도의 `매입 ON/OFF` 제어를 추가했습니다.
- 매입을 꺼도 기존 가격은 보존되며, 다시 켜면 저장된 가격을 그대로 사용할 수 있습니다.

### 낱장별 검수

- 여러 장으로 묶인 품목을 `각 카드별` 항목으로 분리하는 기능을 추가했습니다.
- 분리한 각 낱장은 서로 다른 감가율·최종 가격·사유를 적용할 수 있습니다.
- 분리 저장 중 네트워크 오류가 발생해도 원본 수량이 먼저 사라지지 않도록 저장 순서와 실패 복구를 보강했습니다.

### 운영 참고

- 이번 버전은 별도 Supabase 스키마 변경 없이 현재 `order_items` 구조에서 동작합니다.
- 낱장 분리는 실제 주문 항목을 수량 1 단위로 나누므로 실행 전에 해당 주문의 품목을 확인해 주세요.
- 배포 파일은 `MarinfordKiosk_v0.6.2.exe`입니다.
