## v0.5.2

매입 요청 흐름에서 자주 손이 가던 장바구니 조작과 관리자 카드 관리 흐름을 함께 다듬은 업데이트입니다. 고객 화면에서는 장바구니 수량 조절이 더 직관적으로 보이도록 정리했고, 관리자 화면에서는 카드의 소속 게임과 탭을 수정 화면에서 직접 옮길 수 있도록 확장했습니다.

### 주요 변경

#### 매입 요청 UX

- 장바구니 목록에서 수량 증감 버튼 흐름을 다듬었습니다.
- 수량이 1장일 때 감소 버튼이 삭제 동작으로 보이도록 정리해 삭제 의도를 더 명확하게 만들었습니다.
- 수량 변경 시 총 매입가가 즉시 다시 계산되도록 기존 전역 상태 흐름을 유지하면서 UX를 보강했습니다.

#### 관리자 화면

- 입금자 정보 복사 포맷에서 전화번호를 제거했습니다.
- 복사 결과는 이제 `이름 은행 계좌번호` 형식으로 정리됩니다.
- 매입 요청 편집 화면에서 품목별 매수 조절을 지원합니다.
- 매입 요청 편집 화면에서 품목별 삭제를 지원합니다.
- 카드 정보 수정 모달에 `게임`과 `탭` 선택 드롭다운을 추가했습니다.
- 게임을 바꾸면 해당 게임에 연결된 탭만 보이도록 연쇄 필터링을 적용했습니다.
- 카드 저장 시 `cards` 테이블의 `game_id`, `tab_id`, `category`가 함께 갱신되도록 정리했습니다.
- 카드 추가 시에도 선택한 탭 기준으로 `game_id`, `tab_id`가 함께 저장되도록 맞췄습니다.

#### 데이터 및 레어도 처리

- 동적 레어도 구성을 더 안정적으로 받기 위해 카드 가격 구조의 타입을 커스텀 레어도까지 수용하도록 넓혔습니다.
- 카드 수정 화면과 카드 추가 화면이 설정의 글로벌 레어도 목록을 공통으로 따르도록 유지했습니다.

### 운영 참고

- 특정 게임에 연결된 탭이 하나도 없으면 카드 수정 화면에서 탭 미지정 상태가 될 수 있습니다. 이 경우 게임/탭 관리에서 먼저 탭 연결을 맞추는 것이 가장 안전합니다.
- `탭 없는 게임` 배정을 완전히 사용하려면 `cards.game_id`, `cards.tab_id` 컬럼 추가 SQL 적용이 필요합니다.
- 이번 변경은 `v0.5.2` 릴리스 준비 범위 기준으로 정리됐습니다.
