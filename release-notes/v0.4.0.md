## v0.4.0

키오스크 메인 화면의 시각 구조를 전면 개편한 UI 리뉴얼 업데이트입니다. 화면 우선순위를 다시 잡고, 고객이 카드를 더 빠르게 찾을 수 있도록 레이아웃을 크게 다듬었습니다.

### 주요 변경

- 상단 타이틀을 중앙 드롭 패널 형태로 변경했습니다.
- 게임 선택 UI를 우측 대형 카드 버튼 구조로 재배치했습니다.
- 확장팩 탭을 드롭다운 메뉴로 전환했습니다.
- 탭 드롭다운에 `전체` 보기 옵션을 추가했습니다.
- 설정, 검색, 장바구니 버튼을 하단 플로팅 원형 버튼 구조로 변경했습니다.
- 장바구니 담기 시 플라이 애니메이션을 추가했습니다.

### 운영 참고

- 화면 구조가 이전 버전과 크게 달라졌으므로, 매장 설치 후 고객 동선 기준으로 한 번 더 배치 감각을 확인하는 것을 권장합니다.
