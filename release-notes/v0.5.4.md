## v0.5.4

이번 업데이트는 공개 저장소에 노출될 수 있는 기본 관리자 PIN 정보를 제거하고, 메인 화면 동기화 칩의 시간 표시 기준을 바로잡는 보안 및 운영 안정화 업데이트입니다.

### 주요 변경

#### 관리자 PIN 보안 정리

- 클라이언트 코드에 남아 있던 공개 기본 PIN fallback을 제거했습니다.
- Electron 로컬 설정의 기본 `adminPin` 값을 빈 값으로 변경해, 별도 설정 없이 공개 PIN으로 인증되는 경로를 막았습니다.
- Supabase 설정을 정상적으로 불러온 경우에는 DB에 저장된 관리자 비밀번호만 검증에 사용하도록 정리했습니다.
- DB 연결 실패 시에는 공개 기본 PIN을 사용하지 않고, 운영자가 별도로 설정한 로컬 PIN이 있을 때만 보조 인증 경로를 사용할 수 있도록 변경했습니다.
- 과거 릴리스 노트에 노출되어 있던 기본 PIN 문구를 제거했습니다.

#### 동기화 칩 시간 표시 수정

- 동기화 칩에 표시되던 시간이 `store_settings.updated_at` 기준으로 보이던 문제를 수정했습니다.
- 이제 동기화 칩 시간은 실제 마지막 동기화 완료 시각을 기준으로 표시됩니다.
- 시간 표시는 `Asia/Seoul` 기준으로 고정하고, `KST` 표기를 함께 표시하도록 정리했습니다.

### 버그 수정

- 운영 설정을 변경하지 않았는데도 동기화 칩 시간이 오래된 설정 변경 시각으로 보이던 문제를 수정했습니다.
- Electron 환경에서 로컬 설정 기본값만으로 관리자 인증이 통과될 수 있던 보안상 위험한 fallback 경로를 제거했습니다.

### 운영 참고

- 기존 운영 DB의 관리자 비밀번호는 그대로 유지됩니다.
- 오프라인 환경에서 관리자 진입이 필요하다면 실행 파일 옆 `config.json`에 운영자가 직접 `adminPin`을 설정해야 합니다.
- 새로 생성되는 `config.json`에는 유효한 기본 PIN이 포함되지 않습니다.
