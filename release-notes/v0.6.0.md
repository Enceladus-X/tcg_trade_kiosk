## v0.6.0

이번 업데이트는 고객이 현금보다 마일리지 지급을 더 쉽게 선택하도록 장바구니와 관리자 매입 목록의 정산 방식 UI를 개선한 판촉 강화 버전입니다.

### 주요 변경

- 장바구니의 정산 방식 선택 영역에 마일리지 추가 지급률을 표시하도록 추가했습니다.
- 개별 품목의 마일리지 선택 버튼에 `+10%`처럼 현재 설정된 추가 지급률이 함께 보이도록 개선했습니다.
- `전체 마일리지` 버튼에도 추가 지급률 배지를 표시해 일괄 전환 시 혜택을 바로 인지할 수 있도록 했습니다.
- 장바구니 상단에 `마일리지 선택 시 +10% 추가 지급` 안내 문구를 추가했습니다.

### 관리자 화면

- 관리자 매입 요청 목록의 개별 정산 방식 토글에도 마일리지 추가 지급률을 표시하도록 맞췄습니다.
- 관리자 화면의 `전체 마일리지` 전환 버튼에도 동일한 추가 지급률 배지를 표시합니다.
- 정산 방식 일괄 변경 영역에 마일리지 추가 지급 안내 문구를 추가했습니다.

### UI 조정

- 마일리지 버튼이 과하게 튀지 않도록 그라데이션과 과한 발광 효과는 제거했습니다.
- 배율 표기는 제거하고, 고객이 바로 이해하기 쉬운 `+10%` 표기로 통일했습니다.
- 버튼 내부 텍스트가 줄바꿈되어 찌그러지지 않도록 폭과 줄바꿈 처리를 조정했습니다.

### 운영 참고

- 별도 Supabase 스키마 변경은 필요 없습니다.
- 추가 지급률은 기존 설정의 `mileage_rate` 값을 기준으로 자동 표시됩니다.
- 배포 파일은 `MarinfordKiosk_v0.6.0.exe`입니다.
